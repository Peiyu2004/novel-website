# A Sol in the Mars Outpost 🚀

> An interactive, browser-based survival simulation designed for kids ages 7–12 to experience real space mission trade-offs between life support, power, and radiation shielding. Built for the NASA Space Apps Challenge.

## 🎮 About the Game
Space education for kids often stays too abstract. *A Sol in the Mars Outpost* turns genuine mission constraints into gameplay: every decision involves a strict trade-off where saving power today might cost oxygen tomorrow. 

## 🛰️ Grounded in NASA Open Data
* **Space Weather:** Solar particle events and radiation profiles adapted from **NASA DONKI** archives.
* **Crew Health:** Radiation dosage benchmarks aligned with **NASA OSDR** (Open Science Data Repository) research findings.
* **Environment:** Surface parameters tailored for Mars Jezero Crater and lunar outpost missions.

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS (via CDN), JavaScript (ES6+).
* **Hosting:** GitHub Pages (Zero install, browser-playable).
